


# Community webpage
webpage显眼的位置要一直popup一个 “make a donate”这样的magiclink直接跳到donation页面，再popup 一个 my profile，点进去登录 邮箱密码就可以看到自己的 profile，比如
```
昵称：阿木

累计捐款：HK$2,400
这些捐款具体用来做的具体事情，以及具体具体的对受助者做出了什么影响。要清晰真诚的梳理

设计的有成就感一点
```

supporter wall：build a community
把donor头像排列成一个 supporter mosaic，大量圆形头像图案（website预存随机分配，甚至可以简单生成），然后下面再把合作机构排列，同样圆形头像（机构logo）（like Open Collective）

标题用 “People making this possible”，配合文字：
```
已有 1,284 位支持者和10家机构加入

每一个数字，都代表有人相信这件事值得发生。
```
强调人数而不是总金额。成功的地方是：第一眼看到的不是金额，而是“原来有这么多人共同making this possible”

# Donation webpage
webpage显眼的位置要一直popup一个 our community，点进去就会跳转到 community page
webpage显眼的位置要一直popup一个 my profile，点进去登录 邮箱密码就可以看到自己的 profile

Donation serious的彻底透明，明确到此都收了donation，donation分别都花在了哪些aspect，细致具体的知道钱具体花在了哪里，以及具体的对受助者做出了什么影响。
，要清晰美观但不失serious

下面就是正式的捐款介面：
一开始选择：是否完全匿名捐款，如果选是的话，就直接跳到支付方式。
如果不是完全匿名捐款，
询问用户有没有 donor profile，有的话输入邮箱，密码
没有的话建立一个 donor profile , 输入 邮箱，昵称（不能重复），名字（optional，如果不填就默认为昵称，名字主要用在后台记录和email联系），密码
这里就会建立一个 donor profile而不是到支付成功之后

之后就是选择具体捐款，
用户可以按照前面透明的donation 细节报告选择想要资助的aspect，或者可以选default，然后选择金额，选好之后确定，系统会在底下简单的介绍这个钱预计会用在什么地方，这里不用计算只需要大致说这个aspect都会用捐款做些什么并加一句浪漫一点的话。然后向用户确认跳转支付

支付成功后，
询问用户是否要上supporter wall，要的话问要不要 leave a msg to the community
之后
后台自动计算这个这个金额预期能做到的事，然后发给用户，这里要说的具体详细，要表述的serious和真诚 （这个也会加在memory profile里）
在加上一个随机受助者 motivating的照片 + 亲手写的感谢文字
告诉donor已经发送了类似确认，收据，感谢信的email。
以及告诉donor这笔钱之后具体落地的记录，照片之类的+真实造成的影响都会邮件汇报给donor
