# Help and Educational Resources Update

## What was added

This update adds two new experience areas to the Love 21 prototype:

- A Help page for families and carers
- An Educational Resources page for learning, inclusion and belonging

## Help page

The new Help page provides a welcoming place for families and carers to:

- find practical support guidance
- explore support conversations and next steps
- move from curiosity to connection through volunteering or learning resources

## Educational Resources page

The new Resources page offers a richer learning experience with:

- category-based learning cards
- topic highlights such as neurodiversity, inclusion and celebration of strengths
- a simple FAQ section for common questions

## Where to find it

- Help: /help
- Resources: /resources

## Notes

These pages are designed to extend the existing hackathon prototype with more complete, human-centred content while staying consistent with the current visual style and navigation.
